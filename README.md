# YouTube 排行榜

这是一个免费、无需登录即可在线查看 YouTube 排行数据的网站。点开榜单就能查看前 50 名，点击频道名或视频标题可前往 YouTube。

**[在线查看排行榜](https://wlsjr.github.io/youtube_rank_site/)**

| 榜单 | 排序依据 |
| --- | --- |
| 频道订阅榜 | 按频道订阅数排序 |
| 音乐视频累计播放榜 | 按 Kworb 收录的音乐视频累计播放量排序 |
| 音乐视频近 24 小时播放榜 | 按 Kworb 收录的音乐视频过去 24 小时新增播放量排序 |

数据每天北京时间 **08:00** 开始自动更新。每个榜单标题下方都会显示最近一次成功更新的北京时间，方便判断数据的新鲜程度。
